this is a data engineering repository

Week 1- Step 1: Download any uncleaned dataset from kaggle (dirty_cafe_sales.csv) and upload it in data folder. Step 2: Create a folder named util and inside that folder create 3 separate files (read_csv.py,data_cleaning.py, insights.py ) Step 3: Inside read_csv.py, write the function to read the csv file from data folder. Inside data_cleaning.py, write the python functions to clean the data, Inside insights.py, use the python functions to extract the insights. Step 4: Create an env file to write the environment variables like csv data file path (input and output both). In input file, uncleaned data is present which will be cleaned and then written to output file after cleaning. We may use config.yaml file too. Step 5: Write test cases in test folder to test whether the data_cleaning functions are working fine or not. Step 6: Create a Makefile and write the commands to format the code format or structure. Step 7: Create a run_data_cleaning.bat file and set the event in task scheduler to trigger the event of data_cleaning function on csv data everyday.

Week 2- Step 8: Write python functions in pyspark to get the insights from the dataset. Step 9: Create a postgreSQLQuery.txt file to write the query to extract insights from the dataset
